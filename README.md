#  Finding the Hypotenuse of a Right Triangle Using the Math Library

## Description
This program calculates the hypotenuse of a right triangle using input values and the math library.

## How to Run
1. Open the program file
2. run the program
3. Enter the values for a (first shorter side) and b (second shorter side)
4. Check the hypotenuse displayed on the screen

## Input Needed
- a (first shorter side)
- b (second shorter side)

## Sample Output
Enter the length of side a: 6 

Enter the length of side b: 8

The hypotenuse is: 10.00
